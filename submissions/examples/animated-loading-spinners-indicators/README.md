# Animated Loading Indicators Pack

A clean collection of lightweight, pure-CSS loading animation styles.

## Features
- 4 loader variations designed for multiple contexts:
  - `.em-loader-spin` (Spinning loading ring)
  - `.em-loader-pulse` (Pulsating card loader)
  - `.em-loader-ping` (Expanding radar/ping circle)
  - `.em-loader-dots` (Staggered horizontal bouncing dots)
- Extremely low footprint with performance optimized keyframe transitions.

## Usage
Add classes directly to your markup structure:

```html
<!-- Spinning Loader -->
<div class="em-loader em-loader-spin"></div>

<!-- Bouncing Dots Loader -->
<div class="em-loader-dots">
  <div class="em-loader-dot"></div>
  <div class="em-loader-dot"></div>
  <div class="em-loader-dot"></div>
</div>
```
