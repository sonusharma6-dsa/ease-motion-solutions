Override Examples

Drop any of these into your own stylesheet — no JS, no build step.

/* 1) Re-theme the entire page with two lines */
:root {
  --ease-theme-primary:   #0ea5e9;
  --ease-theme-secondary: #06b6d4;
}

/* 2) Slow every animation down globally */
:root {
  --ease-theme-duration-base: 600ms;
  --ease-theme-duration-slow: 1200ms;
}

/* 3) Per-component theming */
.dashboard-widget {
  --ease-theme-primary: #f59e0b;
  --ease-theme-radius-lg: 1.5rem;
}

Accessibility Built-In

Honors prefers-color-scheme to swap light/dark surfaces automatically, and prefers-reduced-motion to drop all animation durations to 0ms without removing the animation definitions.
