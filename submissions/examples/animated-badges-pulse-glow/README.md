# Animated Badges & Status Indicators

A compact, pure-CSS status indicator and count badge component pack with animated pulsing border glow variants.

## Features
- Pill styling `.em-badge` with rounded corners.
- Three context presets:
  - Primary (Default Blue/Indigo)
  - `.em-badge-success` (Green)
  - `.em-badge-danger` (Red)
- Radial pulsing halo indicator `.em-badge-pulse` with custom keyframe offsets for attention cues.

## Usage
Place badges directly inline within headers, tags, or buttons:

```html
<span class="em-badge em-badge-success em-badge-pulse">Online</span>
```
